# VMemKV 論文アウトライン案

更新日: 2026-09-17 ／ 議論用の初稿

## 中心となる問い

**読み取り方法を使い分けることで、独自のバッファプールを持たない永続 KVS は、どこまで高性能にできるか。**

流れ: 課題 → Read-path Trifecta の原理 → VMemKV での実現 → 効果と限界の検証。

## 章立て

| 章 | 内容 |
| --- | --- |
| 1. はじめに | 研究の背景、問い、提案と貢献。|
| 2. 背景と課題 | OS にページ管理を任せる利点と、一律の読み取り方針の問題。 |
| 3. Read-path Trifecta | 操作・サイズ・常駐状態に応じた読み取り経路の選択。 |
| 4. VMemKV の設計 | 索引と値の分離、base/tail、更新・永続化・回復。 |
| 5. 評価 | 他の KVS との性能比較、Trifecta 単体の効果、保守処理の費用。 |
| 6. 考察と限界 | 有効な条件と、メモリ・OS・機能上の制約。 |
| 7. 関連研究 | 既存手法との共通点と、本研究が加える工夫。 |
| 8. おわりに | 実験で確認できた範囲で、最初の問いに答える。 |

性能の結論と新規性の範囲は、今後の検証で確定する。
